## Benchmarks

| | Puppeteer | OG Engine | Delta |
|---|---|---|---|
| **Render** | ~850ms | **~2ms** | 425x |
| **Memory** | ~200-500MB | **~10MB** | 50x |
| **Concurrency** | ~5-10/instance | **500+/instance** | 100x |
| **Cold start** | ~2-5s | **~50ms** | 100x |
| **Infrastructure** | Chrome + Xvfb + sandbox | **Node.js** | — |
| **i18n** | Full browser | **CJK, Arabic, emoji** | Parity |

## One Request

```bash
curl -X POST https://api.og-engine.com/render \
  -H "Authorization: Bearer oge_sk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"format": "og", "title": "Hello, OG Engine"}' \
  --output hello.png
```
