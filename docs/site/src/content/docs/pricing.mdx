## What Counts as a Render

- `POST /render` = **1 render**
- Each item in `POST /render/batch` = **1 render**
- Failed requests (4xx) = **0 renders**
- `/validate` = **0 renders**, on every plan — it never consumes quota (it is still subject to the request rate limit below)
- `/health` = **0 renders**
- Output format does not change the cost — PNG, WebP, and PDF are **1 render** each

## Quotas and Rate Limiting

These are two separate limits.

**Monthly quota** — how many renders your plan includes. Paid plan quotas reset each billing cycle (the anniversary of your signup date). Free plan quotas reset on the 1st of each month at 00:00 UTC.

**Request rate limit** — how fast you may call the API. `/render`, `/render/batch`, `/render/from-url` and `/validate` are limited to **100 requests per 60 seconds per IP address**. This applies on every plan, including paid plans, and it is independent of your remaining monthly quota.

Every rate-limited response includes the state of the *per-minute* limit:

```
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 99
X-RateLimit-Reset: 1735689600
```

Exceeding the per-minute limit returns `429` with error code `rate_limit_exceeded` and a `retryAfterMs` field. Exhausting your monthly quota returns `429` with error code `quota_exceeded`.

## FAQ

### Can I upgrade mid-cycle?

Yes. You immediately get the higher quota and new features. Billing is prorated — you only pay for the remaining days.

### Does unused quota roll over?

No. Quotas reset to zero each billing cycle (paid plans) or on the 1st of each month (Free plan).

### What happens when I exceed my quota?

Render requests return `429` with error code `quota_exceeded`. `/validate` stays available. Upgrade anytime to restore capacity immediately.

### Can I downgrade?

Yes. Downgrades apply at the start of the next billing cycle. You keep current features until then.

### Do batch items count individually?

Yes. A 50-item batch consumes 50 renders. Quota is checked once before the batch starts, so a batch is either accepted whole or rejected whole with `quota_exceeded` — there is no partial batch.

### Can I use the Free plan forever?

Yes. 500 renders/month, no expiration, no trial clock. PNG and PDF output, every font, every format, every template, and `/validate` at no quota cost are included. WebP output, batch rendering, and CDN caching start on the paid plans.

### Is PDF output included on the Free plan?

Yes. Set `output.format: "pdf"` on any plan, including Free. You get a single-page PDF sized to the render's exact pixel dimensions, and it costs the same one render as a PNG.

### Why is WebP a paid feature?

WebP is where most teams move once they are serving these images to real traffic, so it is the line between evaluating OG Engine and running it in production. It starts on Starter at €10/mo. PNG and PDF stay free.
