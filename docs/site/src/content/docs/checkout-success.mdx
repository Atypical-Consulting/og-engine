## What just happened

Your payment was processed by Stripe and your subscription is now active. Within a few seconds you should receive an email containing:

- Your **API key** (starts with `oge_sk_`)
- A ready-to-use `curl` example
- A link to the Quick Start guide

If you don't see the email within a minute, check your spam folder.

## Quick reference

```bash
# Your API key is in your email — use it like this:
curl -X POST https://og-engine.com/render \
  -H "Authorization: Bearer oge_sk_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{"format":"og","title":"Hello, OG Engine"}' \
  --output hello.png
```

## Need help?

- **Lost your API key?** Email [support@og-engine.com](mailto:support@og-engine.com) with the email you used at checkout.
- **Billing questions?** Use the [Stripe Customer Portal](/api-reference/overview/) (requires authentication).
- **Technical issues?** Open an issue on [GitHub](https://github.com/Atypical-Consulting/og-engine/issues).
