What should the dashboard include?

Select all sections you want in the dashboard. You can always add more later — pick what matters for launch.

1

Overview / Home

Usage meter (calls used / limit), current plan, quick stats (total renders, avg render time). The "at a glance" page.

2

Generated Images Gallery

Browse past renders with thumbnails, metadata (template, format, timestamp), and re-render / download actions. Searchable and filterable.

3

API Keys

View, regenerate, or revoke API keys. Copy-to-clipboard. Show last used timestamp. Support multiple keys per account.

4

Subscription & Billing

Current plan details, upgrade/downgrade buttons, billing history, link to Stripe portal for payment method management.

5

Usage Analytics

Detailed usage charts — calls per day/week/month, breakdown by endpoint, by format, by template. Quota warnings.

6

Custom Templates

Create, edit, preview, and delete custom JSON templates (Scale tier only). Template editor with live preview.

7

Webhooks / Triggers

Manage webhook triggers — create, test, view delivery logs, toggle active/inactive.

8

Account Settings

Email preferences, notification settings, delete account. Basic profile management.
