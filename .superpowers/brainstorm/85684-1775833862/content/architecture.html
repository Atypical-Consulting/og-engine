Key flows:
① Login: GET /auth/login → form → POST /auth/send-link → email with magic link → GET /auth/verify?token=xxx → set session cookie → redirect /dashboard
② Dashboard: Every request sends session cookie → middleware validates → returns HTML fragment → htmx swaps into page
③ API: Bearer token auth (unchanged) → JSON response
④ Swagger: /docs serves Swagger UI → points to /api/openapi.json → spec auto-generated from Zod schemas
